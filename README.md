# SF 2026 旅のしおり

PokémonXP / Pokémon World Championships 2026（2026年8月・サンフランシスコ）向けの
単一HTML旅程アプリ。

ファンが個人的に作ったものです。株式会社ポケモン等とは関係ありません。

## ビルド

```bash
python3 scripts/build_shared.py   # 配布用 → index.html
python3 private/build_mine.py     # 本人用（private/ が必要。このリポジトリには入っていません）
```

セットアップ・仕様・未着手タスクは PROJECT.md を参照。
